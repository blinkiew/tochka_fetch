# TochkaFetch

TochkaFetch отслеживает новые посты со школьным расписанием в сообществе VK, использует Gemini для выбора изображения с расписанием для 10-х и 11-х классов и публикует это изображение в Telegram-канал.

## Настройка

Создайте файл `.env` в корневой директории проекта:

```dotenv
VK_TOKEN=your_vk_service_token
VK_DOMAIN=-152524627
BOT_TOKEN=your_telegram_bot_token
CHANNEL_ID=@tochka_schedule
GEMINI_API_KEY=your_google_ai_studio_key
```

`VK_DOMAIN` — это ID сообщества VK (обычно отрицательное целое число). Переменная `DOMAIN` также поддерживается как устаревший псевдоним. `CHANNEL_ID` может быть юзернеймом канала или числовым ID чата. Telegram-бот должен являться администратором канала с правом публикации сообщений.

Переменная `DATES_PATH` необязательна, по умолчанию используется `dates.json`. В этом файле хранится дата последнего успешно опубликованного поста для каждого филиала. Сохраняйте этот файл при перезапусках, чтобы бот не публиковал старые расписания повторно. `GOOGLE_API_KEY` поддерживается в качестве альтернативы `GEMINI_API_KEY`.

## Локальный запуск

Используйте Python версии 3.12 или новее:

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Сборка и запуск через Docker

Сборка образа из корня репозитория:

```powershell
docker build -t tochka-fetch:latest .
```

Запуск с передачей файла `.env` и именованного volume Docker для сохранения состояния:

```powershell
docker run -d --name tochka-fetch --restart unless-stopped --env-file .env -v tochka-fetch-data:/data tochka-fetch:latest
```

Просмотр логов: `docker logs -f tochka-fetch`. Образ не содержит файл `.env` или локальные тестовые файлы; передавайте секретные данные во время запуска и не вшивайте их в сам образ.

## Дисклеймер

Это не официальный проект. Он републикует информацию о расписании из открытых источников, не связан с администрацией школы и не монетизируется.
