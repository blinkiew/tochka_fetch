# TochkaFetch
Программа для дублирования расписания Школы Дизайна «Точка» в телеграм-канал для упрощения жизни.

## Запуск и настройка
1. Для начала установите необходимые библиотеки: `pip install -r requirements.txt`.
2. Создайте файл переменных окружения со следующими параметрами:

   `VK_TOKEN` – Сервисный ключ доступа API VK. Нужен для получения постов из сообщества.
   
   `DOMAIN` – id сообщества, должен начинаться с минуса. Пример: `-152524627`
   
   `BOT_TOKEN` – Токен телеграм-бота для публикации постов. Токен можно получить через бота [@BotFather](https://t.me/BotFather) в телеграм.

   `CHANNEL_ID` – id/юзернейм группы. Пример: `@tochka_schedule`

 3. Добавьте вашего телеграм-бота в качестве администратора вашего канала и разрешите ему писать сообщения.
 4. Запустите скрипт `main.py`.

## Дисклеймер

Не является оффициальным скриптом. Все данные запрашиваются из открытых источников. Программа является оберткой для упрощения получения доступа к школьному расписанию. Проект не монетизируется.
